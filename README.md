# DnD

This repository holds D&D campaigns.

Each campaign has its own folder. Each campaign folder has a `sessions/`
folder. Each session has its own folder, with a number in front of the name.

## Table rules

These rules apply to all campaigns and one-shots in this repository.

- **No distances.** Do not use feet, squares, a grid, or area shapes such as
  cones and spheres. Use three words:
  - **Close:** next to a creature. A melee attack needs this.
  - **Near:** in the same room. One move takes you there.
  - **Far:** at the other end of a big hall, or out of the room. A Dash takes
    you there.
- A ranged attack or a spell can hit any creature that you can see. The DM
  can say that a target is too far.
- An area effect hits a small number of creatures that stand close together.
  The text of the effect says how many.

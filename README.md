## Overview

**Dice & Destiny** is an independent tabletop roleplaying game.
It uses the rules of fifth edition (2024), so a table that knows those rules
can play it at once.

The System Reference Document 5.2 (SRD 5.2) gives the free core of the
rules. Dice & Destiny puts that core into two books, explains it for new
players, and adds a large set of original content: classes, species,
monsters, magic items, and optional rules. The aim is a full game for a
large world, with no extra books to buy.

The books are built from source. Each push to `main` makes new PDFs in color
for a screen, in black and white for a home printer, and as print-ready
files for a hardcover or a paperback.

## Optional systems

Each system is optional. A table can use one, some, all, or none.

| System | What it adds | Book |
|---|---|---|
| Marks | Blessings, curses, and taints that grow on a track from 0 to 5, with a crisis at 5 | Player's and GM's |
| Bonds | A bond die between two characters, for help, protection, and rivalry | Player's and GM's |
| Techniques | Stances, maneuvers, and spell shapings, paid with technique points | Player's and GM's |
| Legend paths | Five tiers of renown for great deeds, to level 20 and after | Player's and GM's |
| Journeys | Travel days with roles, weather, encounters, and a supply die | GM's, with a summary for players |
| Factions and renown | Ranks in guilds, orders, and courts, with their rewards | GM's |
| Injuries and scars | Lasting wounds that the player chooses to take, and the scars that they leave | GM's |
| Crafting and gathering | Materials from monsters and biomes, and recipes at the SRD costs | GM's |

### Download the PDFs

Go to [Releases](https://github.com/Stiven-Gjekaj/dice-and-destiny/releases).
Each book has five files in a release. Choose the files for what you
want to do:

| Use | File | What it is |
|---|---|---|
| Read on a screen | `...-screen.pdf` | Color, with a front cover. The contents link to the chapters, and the bookmarks list the parts and chapters. |
| Print at home | `...-home-print.pdf` | A4, black and white, with a front page and a blank back. Print it on both sides. The wide inside margin has space for punched holes. |
| Print a hardcover | `...-lulu-interior.pdf` and `...-lulu-cover.pdf` | The interior with no cover, and the wraparound cover for a Lulu A4 casewrap hardcover. |
| Print a paperback | `...-lulu-interior.pdf` and `...-paperback-cover.pdf` | The same interior, and a full color A4 paperback cover with 3 mm bleed. Check the spine width with the cover template of your printer. |

- A **preview** release comes from each change to the books. It has the
  files of all books.
- An **edition** release (tag `edition-N`) is a finished edition of the two
  Compendiums. The rolling release `compendium-latest` has its files.
- A **Waking** release (tag `dawnwatch-waking-N`) is a finished version of
  The Dawnwatch, Book One: Waking. The rolling release
  `dawnwatch-waking-latest` has its files.

To build the books yourself, read [`compendium/README.md`](compendium/README.md).
